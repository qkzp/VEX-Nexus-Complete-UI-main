This file is a launcher guide. The real multi-user application runs at localhost:3000.

First start

Open this extracted folder in VS Code, make sure Docker Desktop is running, then run:

npm install
npm run local

The second command starts PostgreSQL, updates Prisma to the included schema, and launches the Next.js site. Keep the terminal open while using PitRelay.
