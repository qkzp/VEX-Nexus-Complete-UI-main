BOLTCANVAS - LOCAL DEVELOPMENT
==============================

This project is a Next.js workspace for VEX robotics teams. Local development
uses PostgreSQL and the normal account flow in the app.

1. Start Docker Desktop.
2. Copy `.env.example` to `.env`.
3. Set `AUTH_SECRET` in `.env` with a random value. For example:

   node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"

4. Install dependencies and start the local database and app:

   npm install
   npm run local

5. Open http://localhost:3000.
6. Create an account, complete onboarding, then create or join a team.

The local database uses the connection strings already provided in
`.env.example`. The first launch prepares the Prisma schema with Docker
Compose. Later launches keep the team, robot, task, and test data you create.

Useful commands
---------------

`npm run local` starts PostgreSQL, prepares Prisma, and runs Next.js.
`npm run local:stop` stops PostgreSQL without deleting its volume.
`npm run db:generate` regenerates the Prisma client.
`npm run db:deploy` applies committed migrations.
`npm run dev` starts Next.js when the database is already prepared.

For a local reset, set `ALLOW_DEV_RESET=true` in `.env` and open
http://localhost:3000/dev-reset while signed in. Do not enable that setting on
a production deployment.

Before sharing a change, run:

   npm run lint
   npx tsc --noEmit
   npm test
